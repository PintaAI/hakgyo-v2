# Brand assets

Copied unmodified from `apps/mobile/assets/brands/` for use by the web app.
See the mobile asset README for source and trademark notes.

- `zoom.png` — Zoom brand icon.
- `whatsapp.svg` — WhatsApp standalone logomark.
- `android-head.svg` — Android robot head (flat), from
  `https://developer.android.com/static/images/brand/android-head_flat.svg`
  (Android brand guidelines, retrieved 2026-10-30). Pages that show it must
  carry the attribution line: "The Android robot is reproduced or modified
  from work created and shared by Google and used according to terms described
  in the Creative Commons 3.0 Attribution License."

There is no Apple counterpart: Apple's marketing guidelines forbid the
standalone Apple logo. Link to the App Store only with Apple's official
"Download on the App Store" badge, and only to the App Store product page.
